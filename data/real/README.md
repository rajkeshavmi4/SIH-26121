# Real drilling data

This directory contains a small real-data subset from the Equinor Volve field dataset.

- Source subset: https://github.com/f0nzie/volve-drilling
- Official dataset page: https://www.equinor.com/energy/volve-data-sharing
- Scope: WITSML XML logs and BHA data for three Volve wells
- Verified locally: 3 well directories, 312 XML files, approximately 208 MB expanded

This is real North Sea drilling data, not OIL data and not synthetic demo data. Keep its original source and licence terms when redistributing it. The full Equinor release is much larger and should be accessed through the official Equinor data platform.
